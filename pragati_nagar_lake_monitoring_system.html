Architecture deep-dive
Solar panel (5 W, on lid)
Charges the 3000 mAh LiPo battery during daylight. No grid power needed — node can float anywhere on the lake without cables. At 5 W and 5 h peak sunlight (Hyderabad avg), it generates ~25 Wh/day, enough to run the node at low-power mode indefinitely.
Arduino Nano (microcontroller brain)
Wakes every 60 s, reads all 5 sensor probes, packages a tiny JSON payload (pH, DO, turbidity, TDS, temperature + node ID + timestamp), sends it via LoRa, then sleeps. Sleep current ~20 µA — this is how battery life exceeds 12 h even without sun. Total cost: ₹350.
LoRa module SX1278 (wireless radio)
LoRa = Long Range radio. Transmits tiny packets up to 5 km on 433 MHz using very little power (50 mW). Pragati Nagar Lake is ~600 m across — a single gateway on the lake bund can receive all three nodes simultaneously. No SIM card, no WiFi, no monthly bill. Module cost: ₹450.
Submerged sensor probes (5 parameters)
pH probe — measures acidity. Normal lake: 6.5–8.5. Sewage drops this fast.
DO probe — dissolved oxygen. Below 5 mg/L, fish start dying. Below 2, it's a dead zone.
Temperature sensor — hot industrial discharge heats the lake, lowers DO solubility.
Turbidity sensor — laser scatter measures cloudiness (NTU). Sewage/silt = high NTU.
TDS sensor — total dissolved solids. Detects salts, heavy metals, agricultural runoff.
IP67 sealed enclosure + SD card logger
IP67 means waterproof up to 1 m for 30 min — safe from rain, waves, and splashing. The SD card saves every reading locally as a CSV. If the LoRa connection drops (interference, node out of range), no data is lost — it syncs when reconnected. Enclosure cost: ₹800.

LoRa gateway (Raspberry Pi 4 on the bund)
The Pi runs a LoRa receiver script 24/7. When a sensor node transmits (every 60 s), the Pi decodes the packet and forwards it to the cloud server using MQTT — a lightweight IoT messaging protocol. The Pi also has a 4G dongle for internet and a backup local server, so even if cloud is unreachable, data is stored locally. Cost: ₹6,000 (Pi + antenna + enclosure).
Backend — Node.js + TimescaleDB
An Express API server receives MQTT messages, validates them (checks for sensor drift, missing values), and writes every reading into TimescaleDB. TimescaleDB is purpose-built for time-series data — it stores millions of rows of (timestamp, node_id, ph, do, turbidity, tds, temp) efficiently with automatic compression. An alert engine runs checks: if pH < 6.5 OR DO < 4 OR turbidity > 50 NTU → it fires an SMS to GHMC and a push notification to the mobile app.
Admin dashboard (web app + WebSocket)
A React web app connects to the backend via WebSocket — a live two-way connection. When Node B sends a new reading, the server pushes it through the WebSocket and the dashboard updates instantly without any page refresh. Authorities at GHMC or Hyderabad Lake Conservation Committee can log in, see all three nodes, view historical trends, export CSV reports, and acknowledge alerts.
Citizen reporting mobile app
Any resident near Pragati Nagar Lake can scan a QR code at the lake entrance. The app (React Native / Flutter) opens a simple form: take a photo, tap a GPS pin on the lake map, select issue type (sewage smell / garbage dumping / oil slick / fish kill / other), add a 1-line description, and submit. The report hits the same backend API and appears in the admin dashboard within 5 seconds. No login required — just the QR scan.
Public LED display board at the lake
A low-cost outdoor LED board (₹4,000) polls the public API every 5 minutes and shows current water quality status as a colour-coded safety index: GREEN (safe), YELLOW (caution), RED (dangerous). Residents walking past can see immediately if the lake is healthy. No app download required.

// Pragati Nagar Lake — Sensor Node Firmware // Runs on Arduino Nano, wakes every 60 seconds #include <SPI.h> #include <LoRa.h> #include <OneWire.h> const char* NODE_ID = "node_B"; // Change per node void loop() { // 1. Read all sensors float ph = readPH(); // 0–14 scale float do_mgl = readDO(); // mg/L dissolved oxygen float temp = readTemp(); // °C int turbNTU = readTurbidity();// NTU int tds = readTDS(); // ppm // 2. Build compact JSON payload String payload = "{"; payload += "\"id\":\"" + String(NODE_ID) + "\","; payload += "\"ph\":" + String(ph, 1) + ","; payload += "\"do\":" + String(do_mgl, 1) + ","; payload += "\"t\":" + String(temp, 1) + ","; payload += "\"ntu\":" + String(turbNTU) + ","; payload += "\"tds\":" + String(tds) + "}"; // 3. Transmit over LoRa (5 km range, 50 mW) LoRa.beginPacket(); LoRa.print(payload); LoRa.endPacket(); // 4. Also save locally to SD card saveToSD(payload); // 5. Sleep 60 seconds to save battery LowPower.powerDown(SLEEP_8S, ADC_OFF, BOD_OFF); }
Node.js Backend alert engine — runs on the cloud server
// Alert engine — checks thresholds after every reading // Pragati Nagar Lake specific thresholds const THRESHOLDS = { ph: { min: 6.5, max: 8.5 }, // Normal lake pH do: { min: 4.0 }, // mg/L — below = fish stress ntu: { max: 50 }, // NTU — above = sewage risk tds: { max: 500 }, // ppm — above = heavy metals t: { max: 32 } // °C — thermal pollution }; function checkAlerts(reading) { const alerts = []; if (reading.ph < THRESHOLDS.ph.min) alerts.push(`pH critically low: ${reading.ph} at ${reading.id}`); if (reading.do < THRESHOLDS.do.min) alerts.push(`Low dissolved oxygen: ${reading.do} mg/L — fish kill risk!`); if (reading.ntu > THRESHOLDS.ntu.max) alerts.push(`High turbidity: ${reading.ntu} NTU — possible sewage`); if (alerts.length > 0) { sendSMS_to_GHMC(alerts); // Text GHMC officials broadcastWebSocket(alerts); // Push to dashboard sendPushNotification(alerts); // Notify mobile app users logToDatabase(reading, alerts); // Store for analysis } }
